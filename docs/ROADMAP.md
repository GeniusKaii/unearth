# Roadmap

## v0.1（现在）

- 只读打开分区/整盘/镜像（`vol:` / `disk:` / `img:`）
- 签名雕刻：JPEG、PNG、GIF、BMP、TIFF/RAW、HEIC/AVIF、MP4/MOV/3GP/M4A、AVI/WAV/WebP、PDF、ZIP/DOCX/XLSX/PPTX、OLE(DOC/XLS/PPT/MSG)
- NTFS `$MFT` 删除记录恢复：原名、原目录、四个时间戳、runlist 取数
- EXIF（拍摄时间/相机/GPS/尺寸/方向）、MP4 时长与创建时间
- 精确去重（sha256）、推荐度打分、按天时间线
- 离线相册：筛选、收藏、来源追溯、导出清单
- markdown 报告、按日期分目录导出
- 合成镜像自检 + 44 个单元测试

## v0.2 让它更"能捞"（下一个月内）

- **exFAT / FAT32 删除目录项**：旧 SD 卡、U 盘的主力格式。拿到 `IMG_1234.JPG` 这种原名，比雕刻出来的 `jpeg_0x1a2b` 好用太多。exFAT 的目录项布局固定，删除标记是 `0x05`，可行。
- **碎片 JPEG 拼接**：JPEG 的 restart marker 和量化表能判断"下一段是否还是同一张图"，把被覆盖中间几百字节的照片拼回可看。
- **近似去重**：dHash/感知哈希，同一个场景连拍、微信转发过的压缩版本。
- **HEIC 缩略图**：HEIC 里通常也有预览图（`ispe` + 缩略图 item），抽出来就不用 Pillow 解码。
- **扫描速度**：把"找魔数"和"解析"分离到两个进程，解析走队列；实测 200 MB/s 瓶颈在解析不在读。
- **进度更准**：用已扫字节和命中密度估算剩余时间（现在是线性，遇到大文件会跳）。

## v0.3 「挖掘丢失的工作文件」——这条线对别人更有用

用户场景：离职交接、项目收尾、硬盘换机，找的是 `.docx/.xlsx/.pptx/.pdf/.pst`，不是照片。

- **办公文档的"内容"而不只是容器**：DOCX 解 `word/document.xml` 抽正文前 200 字、标题、作者、修订时间；XLSX 抽 sheet 名和首个非空行；PPTX 抽标题。有了文字就能搜、能聚类。
- **文档指纹与版本串联**：同一份文档的 12 个版本，按"正文相似度 + 修改时间"排成一条版本链，告诉你"这是最终版，前面 11 个是过程稿"。
- **邮件与聊天记录**：`.pst/.ost`（Outlook）、`.eml`、`.msg`、微信/QQ 的 SQLite 库。这是"工作痕迹"密度最高的地方，也是格式最脏的地方。
- **按项目聚类**：文件名、正文关键词、时间窗、同目录，四路信号合成"项目"；一个项目一个时间线。
- **关键词/实体提取**：客户名、项目号、金额、日期。不接大模型也能做——正则 + 词频先上一版，之后再谈 embedding。
- **导出成"交接包"**：按项目分目录 + 一份 `manifest.md`（每个文件哪来的、什么时间、跟谁相关）。

对应 CLI 草案：

```powershell
unearth scan vol:E: -o D:\dig\e --profile docs
unearth ntfs vol:E: -o D:\dig\e
unearth docs D:\dig\e --extract-text --cluster      # 抽正文 + 项目聚类
unearth timeline D:\dig\e --project 辽阳             # 一个项目的时间线
```

## v0.4 让它不像命令行工具

- 本地只读 HTTP 服务 + 更好的相册（地图视图、按相机/镜头分组、事件聚类）
- 人脸聚类（可选，本地跑，照片不出机器）
- 进度条和"预计还剩"做成 GUI；磁盘选择用下拉框
- 一键"从插上盘到出相册"的向导

## 非目标

- 不做对 SSD 的"深度恢复"承诺——TRIM 之后物理上就没了，说能做是骗人。
- 不做磁盘写操作（分区修复、引导修复），那是另一个工具的事。
- 不做云端上传。所有数据留在本机。
